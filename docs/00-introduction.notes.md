# 开篇作者备注

## 范围与读者

- 面向了解家庭路由器、手机 App 和基本网络概念的读者；默认不具备 Matter、Thread 或 Zigbee 背景。
- 本次为中文开篇介绍，不生成英文版、具体选型方案或后续章节正文。
- 贯穿示例为本地规则驱动的夜间开门亮灯；涉及状态迁移和故障判断的内容是明确假设下的教学推演，不是设备实测。
- 术语约定：控制平台执行规则；Zigbee 协调器与接入软件共同完成设备接入；Thread 边界路由器提供 IP 路由。物理中枢可合并部署这些角色。

## 来源与边界

- 正文列出七项官方来源，核对日期为 2026-11-06。MQTT 引用固定的 5.0 标准版，其余在线文档的后续修订可能改变具体实现说明。
- Matter 的设备交互模型、Thread 的路由职责、MQTT 的消息传递职责分别引用对应来源，不从单个云平台推断所有厂商实现。
- 图 1 是参考模型，省略了 AP、交换机、消息重试、凭据建立和设备内部进程。方框表示逻辑角色，不表示必须单独购买的硬件。
- 本篇没有声称对照度、时延、设备兼容性、离线可用性或任何产品执行过实测。部署验证应另行记录设备、固件、配置、故障条件和结果。
- 原有方案明细保留在工作目录，其完整历史入口是 `archived_main`；本次只调整新内容的阅读入口。
